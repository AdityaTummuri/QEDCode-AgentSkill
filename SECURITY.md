# Security

Please report vulnerabilities through GitHub's private vulnerability reporting
(**Security → Report a vulnerability** on this repository), never in a public issue. You will get
an answer within a week.

In scope: instructions in the skill that could make an agent run something unsafe, weaken a test,
or send code or keys somewhere it should not; anything in the packaged zip that differs from this
repository. Problems in the QEDCode engine itself go to
[QEDCode's security policy](https://github.com/AdityaTummuri/QEDCode/security/policy).
